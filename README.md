# Projeto Integrador: Modelagem de Dados e UML - XPTO Investimentos

O objetivo principal do projeto foi migrar o gerenciamento de dados da empresa XPTO Investimentos (que antes era feito de forma ineficiente em planilhas eletrônicas) para um ambiente de banco de dados relacional normalizado até a 3ª Forma Normal (3FN), além de mapear as regras de negócio utilizando diagramas UML.

## 🎓 Estudante
- **Nome:** Andreza Kimberly
- **Curso:** Engenharia de Software
- **Instituição:** Gran Centro Universitário

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **MySQL Workbench / drawDB** (Modelagem Relacional e Scripts SQL)
- **Draw.io** (Diagramas de Caso de Uso e Classes UML)

## 📌 Conteúdo do Repositório (Etapas do Projeto)
- **1_script_banco_xpto.sql:** Script DDL unificado e revisado para criação das tabelas relacionais sem redundâncias.
- **2_diagrama_er_xpto.png:** Modelo Entidade-Relacionamento (MER) mostrando as 7 tabelas normalizadas e seus relacionamentos (1:N e N:M).
- **3_diagrama_casos_de_uso.png:** Diagrama UML mapeando os atores (Cliente, Funcionário, Administrador) e suas ações no sistema com a relação <<extend>>.
- **4_diagrama_de_classes.png:** Estrutura de classes UML detalhando os conceitos de herança a partir da classe base Usuário, além de associações e composições.
